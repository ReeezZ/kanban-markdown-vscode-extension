# Card folder layout

Brainstorm: should cards live in folders, one per status or some other split, instead of one flat folder plus `done/`? Upstream issue #65 asks for a folder per status, so an agent can read only the open cards. Moving a card between folders breaks relative links, as the move into `done/` already can, so this only works if the extension repairs links itself.

Open: whether to use folders at all, and how. Related: [`proper-links-and-link-types-2026-10-23`](proper-links-and-link-types-2026-10-23.md) (link repair on move), [`card-checks-in-extension`](card-checks-in-extension.md).
