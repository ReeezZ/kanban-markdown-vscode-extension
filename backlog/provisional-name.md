# Provisional name

**Goal:** the fork has a provisional name, used for the repository and the README, so the project can be talked about under its own name. It can change until the extension is registered in [`fork-name-and-publisher`](fork-name-and-publisher.md).

The shortlist and its checks are in [`fork-name-and-publisher`](fork-name-and-publisher.md) (top pick Laneboard). Nothing in `package.json`, the settings prefix or the publisher changes here; those wait for Phase 5.

**Done when**

- [ ] a name is chosen
- [ ] the GitHub repository is renamed to match, and the local `origin` URL points to the new name
- [ ] links to the old repository name in the docs and the README are updated
- [ ] the roadmap and [`fork-name-and-publisher`](fork-name-and-publisher.md) say the name is provisional, and where it is confirmed

**Open questions**

- Rename the repository, or keep its name and only change what the README calls the project? Renaming keeps the fork link to upstream and GitHub redirects the old URL.

**Needs:** none
