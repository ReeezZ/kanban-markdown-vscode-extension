# Provisional name

**Goal:** the fork is called **Markan**, a provisional name, in the docs, so it can be talked about as its own project. The name can still change until it's registered in [`fork-name-and-publisher`](../fork-name-and-publisher.md).

Chosen 2026-10-23. Bar for a name: no live product, extension or domain with users in the same niche; tiny hobby repos are fine. Checked on the Marketplace, Open VSX, npm, GitHub and the web: nothing uses "Markan" (the nearest is the unrelated Markane extension, 42 installs). Dropped: Markboard (markboard-io/markboard, a markdown whiteboard with 244 stars and markboard.io; also close to Kanboard), Markban (two small markdown-kanban repos), Kanmark (an existing VS Code extension), Laneboard (names one feature, not the tool). "Kanban" stays visible in the display name or tagline, e.g. "Markan – Markdown Kanban board".

The GitHub repository keeps its name. Nothing in `package.json`, the settings prefix or the publisher changes here; those wait for Phase 5. The README presents the name in [`readme-rework`](readme-rework.md).

**Done when**

- [x] [`fork-name-and-publisher`](../fork-name-and-publisher.md) names Markan as the provisional name, with the bar and the checks, in place of its old shortlist
- [x] the roadmap's Phase 1 Done when names Markan and no longer says the repository carries the name

**Out of scope:** renaming the GitHub repository; the README itself ([`readme-rework`](readme-rework.md)).
